## 이번 세션에서 확정된 설계 결정

### 1. 인터랙션 방식: 서랍 슬라이드

**이전 방식(test 브랜치):** 클릭 시 아이디어 레이어가 뒤로 사라지고 도구 레이어가 앞으로 떠오르는 3D 플립 (`card-scoop` / `tool-swell` keyframes). 두 레이어가 앞뒤로 교체됨.

**현재 방식(이 브랜치):** 아이디어 레이어는 그대로 유지. 도구 레이어가 카드 하단 아래로 슬라이드되어 내려옴. 아이디어와 도구를 동시에 볼 수 있음.

**선택 이유:** 아이디어 내용을 보면서 도구 설명을 함께 확인하는 흐름이 더 자연스럽다는 판단. Figma 시안 Frame 1387 기준.

---

### 2. 도구 레이어 치수 (Figma 시안에서 측정한 값)

| 항목 | 값 | 근거 |
|------|----|------|
| 도구 레이어 width | 320px | Figma 시안 직접 측정 |
| 카드 width | 356px (유지) | 기존과 동일 |
| 정렬 | `margin: 0 auto` (가운데) | 좌우 각 18px 여백 |
| idle 노출 높이 (peek) | 42px | 기존과 동일 |
| 아이디어 레이어와 겹침 | 20px | Figma 시안 측정값 (`--overlap`) |

> **주의:** `--overlap: 20px` (CSS), `TOOL_OVERLAP = 20` (App.jsx), `padding-top: var(--overlap)` (도구 레이어 펼침 시) — 세 곳이 반드시 같은 값이어야 합니다.

---

### 3. 접기 트리거: peek의 ArrowUp 아이콘

- **idle 상태** peek: `[카테고리 텍스트]` + `[아이콘 + 도구명 칩]`
- **펼침 상태** peek: `[카테고리 텍스트]` + `[ArrowUp 아이콘]` → 클릭 시 접기

도구 레이어 전체 클릭이 아니라 **peek 영역만** 접기 트리거. 도구 설명 텍스트 클릭은 아무 동작 없음.

**이렇게 분리한 이유:** 사용자가 도구 설명을 읽는 중 실수로 접히는 것을 방지.

> **UX 미결 사항:** peek이 클릭 가능하다는 것을 사용자가 발견할 수 있는지 확인 필요. hover 시 배경색 변화 등 affordance 추가를 고려 중.

---

### 4. 하위 노드 y좌표 이동 (펼침 시 겹침 방지)

도구 레이어를 펼치면 하위 노드들이 아래로 밀리고, 접으면 복귀합니다.

**delta 계산 공식:**
```
delta = toolHeight(DOM 실측) - OVERLAP(20) - PEEK_HEIGHT(42)
      = toolHeight - 62
```
delta는 "도구 레이어가 펼쳐지며 카드 아래로 **보이는 하단이 자라난 양**"이다.
idle 시 카드 아래로 보이는 부분은 peek 42px뿐이므로, baseline은 dagre의 ranksep(100)이
아니라 **peek 높이(42)** 가 되어야 한다. 이 값만큼만 하위 노드를 내리면 각 노드가 펼치기
전 가지고 있던 간격을 **실제 위치와 무관하게** 그대로 보존하므로, 사용자가 노드를 옮긴
뒤 도구 레이어를 펼쳐도 겹치지 않는다.

`delta > 0` 일 때만 노드를 이동. toolHeight가 62px 이하면 도구 레이어가 기존 peek보다
더 내려오지 않으므로 이동 없음.

> **주의:** `PEEK_HEIGHT = 42` (App.jsx) 는 `LayerStackNode.jsx`의 `PEEK_HEIGHT = 42`와
> 반드시 같은 값이어야 합니다. 한쪽을 바꾸면 다른 쪽도 바꿔야 합니다.

> **과거 버그(수정됨):** 기준값을 peek(42)이 아니라 ranksep(100)으로 잡아 `delta = toolHeight - 120`
> 으로 계산했었음. 기본 dagre 위치에서는 자식이 도구 레이어에 딱 붙는 정도로 간신히 동작했으나,
> 사용자가 노드를 부모 쪽으로 당겨놓으면 delta가 부족해 도구 레이어와 자식 카드가 겹쳤다.

## 알려진 문제

### 새 카드 추가 시 y좌표 초기화

**증상:** 도구 레이어가 펼쳐진 상태에서 모달로 새 파생카드를 만들면, 하위 노드들의 y좌표가 dagre 재레이아웃으로 초기화되어 밀어놓은 간격이 사라집니다.

**원인:** `nodesInitialized` 상태가 새 노드 추가 시 다시 `true`가 되면서 App.jsx의 레이아웃 effect가 재실행됩니다.

**현재 상태:** 미해결. 실험 브랜치라 허용 범위로 판단. 해결하려면 레이아웃 재계산 후 현재 열린 노드의 delta를 다시 적용하는 로직이 필요합니다.
