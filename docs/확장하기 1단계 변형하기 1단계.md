# 확장하기 1단계 변형하기 1단계

### 확장하기 (BCC 11개) 방향성 선택 텍스트 내용 고정

방향성 1: 지금 있는 기능이나 요소를 없애거나 다른 것으로 바꿔보고 싶다

해당 도구는 제거, 대체, 분할·분리입니다.

이유는 세 도구 모두 기존에 존재하는 요소를 건드리는 방식이기 때문입니다. 없애거나, 다른 것으로 바꾸거나, 나누는 행위가 같은 사고 방향입니다.

방향성 2: 기존 요소를 합치거나 새로운 요소를 더해보고 싶다

해당 도구는 용도통합, 결합, 복제입니다.

이유는 세 도구 모두 더하는 방향의 사고입니다. 두 역할을 하나로 합치거나, 서로 다른 것을 연결하거나, 기존 요소를 복사해서 추가하는 방식이 같은 사고 방향입니다.

방향성 3: 당연하다고 여겼던 것을 반대로 뒤집거나 새롭게 정의해보고 싶다

해당 도구는 역전, 재정의입니다.

이유는 두 도구 모두 기존의 전제를 뒤집는 방식입니다. 역전은 위치·순서·속성을 반대로 하고, 재정의는 고객과 문제 자체를 새롭게 봅니다. 둘 다 "당연하다고 생각한 것을 의심한다"는 사고 방향이 같습니다.

방향성 4: 전혀 다른 분야나 상황에서 힌트를 가져와 적용해보고 싶다

해당 도구는 유추, 연결, 속성 의존성입니다.

이유는 세 도구 모두 외부에서 실마리를 찾는 방식입니다. 유추는 다른 시스템의 원리를 가져오고, 연결은 관련 없는 두 요소를 잇고, 속성 의존성은 외부 환경과 내부 속성 간의 새로운 관계를 만듭니다. 모두 현재 아이디어 밖을 보는 사고 방향입니다.

### 변형하기 (ERRC 4개) 방향성 선택 텍스트 내용 고정

방향성 1: 지금보다 더 강하게 밀어붙여야 할 것이 있다

해당 도구는 증가입니다.

이유는 증가가 현재 있는 요소의 수준을 표준 이상으로 높이는 것이기 때문입니다. 사용자 입장에서 "이미 있는데 더 잘하고 싶다"는 욕구와 일치합니다.

방향성 2: 너무 복잡하거나 과한 부분을 줄이고 싶다

해당 도구는 감소입니다.

이유는 감소가 현재 있는 요소를 표준 이하로 낮추는 것이기 때문입니다. "덜어내면 오히려 좋아질 것 같다"는 사용자의 직관과 연결됩니다.

방향성 3: 아직 없지만 있으면 좋을 것을 새로 만들고 싶다

해당 도구는 창출입니다.

이유는 창출이 기존에 없던 요소를 새롭게 만드는 것이기 때문입니다. "지금 없는 것"에 집중하는 사고 방향입니다.

방향성 4: 당연하다고 여겼던 것을 과감하게 없애고 싶다

해당 도구는 제거입니다.

이유는 ERRC의 제거가 업계에서 당연하게 여겨지는 요소를 없애는 것이기 때문입니다. BCC의 제거와 비슷해 보이지만 ERRC 제거는 업계 표준에 대한 질문이라는 점에서 다릅니다.
