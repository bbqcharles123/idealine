# 아이디어 카드의 구성과 작동 방식

아이디어 카드(노드)는 하나의 아이디어를 담는 기본 단위입니다.
단순한 텍스트 박스가 아니라, **두 개의 레이어가 위아래로 겹쳐 쌓인 구조**로 되어 있어
하나의 카드 안에서 "아이디어 자체"와 "그 아이디어를 다루는 도구"를 함께 보여줍니다.

---

## 1. 카드는 두 개의 레이어로 이루어져 있다

| 레이어 | 위치 | 담는 내용 |
|--------|------|-----------|
| **아이디어 레이어** | 위 (앞쪽) | 아이디어의 제목과 본문 내용 |
| **도구 레이어** | 아래 (뒤쪽) | 이 아이디어를 만들 때 사용한 도구 설명, 또는 다음 파생 카드를 만들 때 쓸 도구 추천 |

두 레이어는 같은 자리에 겹쳐 있지만, **아이디어 레이어가 도구 레이어보다 앞(위)에 놓입니다.**
그래서 평소에는 아이디어 레이어가 카드의 주인공처럼 보이고,
도구 레이어는 그 뒤에 숨어 있습니다.

```
   ┌─────────────────────────────┐
   │   아이디어 레이어 (앞)        │
   │   · 제목                     │
   │   · 본문 내용                │
   │                             │
   ├─────────────────────────────┤  ← 도구 레이어의 하단만 살짝 보임
   │   아이디어 생성 도구  [복제] │      (peek 영역)
   └─────────────────────────────┘
```

---

## 2. 도구 레이어는 "하단부만" 보이도록 되어 있다

도구 레이어는 아이디어 레이어보다 아래로 조금 더 길게 뻗어 있어서,
**카드 맨 아래에 도구 레이어의 하단 띠(아래쪽 일부)가 살짝 삐져나와 보입니다.**

이 살짝 보이는 띠를 **peek(엿보기) 영역**이라고 부릅니다.
peek 영역은 도구 레이어로 들어가는 "손잡이" 역할을 합니다.

평소(접힌 상태)의 peek 영역에는 두 가지 정보가 표시됩니다.

- **왼쪽**: 이 도구가 어떤 성격인지 안내하는 라벨
  - 일반 카드 → `아이디어 생성 도구`
  - 직접작성 카드 → `아이디어 발전 도구 추천`
- **오른쪽 칩**: 실제 도구 이름과 아이콘 (예: `복제`, `제거`, `확장하기`)

즉, 카드를 펼치지 않아도 **"이 아이디어가 어떤 도구와 연결되어 있는지"** 를
하단 띠만 보고도 짐작할 수 있습니다.

---

## 3. 클릭하면 두 레이어가 자리를 바꾼다 (인터랙션)

peek 영역(또는 도구 레이어)을 **클릭하면 카드가 펼쳐지는 인터랙션**이 일어납니다.
마치 카드 묶음(큐카드)을 한 장 넘기는 듯한 3D 애니메이션과 함께,
**앞뒤 레이어의 역할이 뒤바뀝니다.**

### 펼칠 때 (아이디어 → 도구)
1. 앞에 있던 **아이디어 레이어가 뒤로 넘어가며 사라집니다.**
2. 뒤에 숨어 있던 **도구 레이어가 앞으로 떠오릅니다.**
3. 떠오른 도구 레이어에는 그동안 가려져 있던 내용이 모두 드러납니다.
   - 도구 이름(아이콘 포함)
   - 도구에 대한 설명
4. peek 영역의 텍스트는 `아이디어 확인하기` 로 바뀝니다.

### 접을 때 (도구 → 아이디어)
펼친 상태에서 `아이디어 확인하기` 를 클릭하면,
**위 과정이 정확히 거꾸로 재생되어** 도구 레이어가 다시 뒤로 가라앉고
아이디어 레이어가 앞으로 돌아옵니다.

```
   [접힘]                    클릭                   [펼침]
 ┌──────────┐                          ┌──────────┐
 │ 아이디어  │   ──────────────────▶   │  도구    │
 │  (앞)    │                          │  (앞)    │
 ├──────────┤                          │  · 도구명 │
 │ peek띠   │   ◀──────────────────   │  · 설명   │
 └──────────┘   "아이디어 확인하기"     ├──────────┤
                                       │아이디어확인│
                                       └──────────┘
```

이 "넘기기" 연출 덕분에 사용자는 **한 장의 카드 안에서**
아이디어 면과 도구 면을 자연스럽게 오갈 수 있습니다.

---

## 4. 도구 레이어의 내용은 카드 종류에 따라 달라진다

도구 레이어가 보여주는 도구는 카드가 어떻게 만들어졌는지에 따라 성격이 다릅니다.

| 카드 종류 | 도구 레이어가 보여주는 것 | 색 계열 |
|-----------|--------------------------|---------|
| **확장하기 카드** | 이 아이디어를 만든 확장 도구 설명 (제거·대체·결합·복제 등) | 초록 |
| **변형하기 카드** | 이 아이디어를 만든 변형 도구 설명 (증가·감소·창출·제거) | 보라 |
| **직접작성 카드** | 다음 단계에서 쓰면 좋을 도구를 **추천** (AI가 제안) | 청록 |

- **확장/변형 카드**는 "이 아이디어가 **어떤 도구로 만들어졌는지**"를 돌아보게 합니다.
- **직접작성 카드**는 "다음에 **어떤 도구로 발전시키면 좋을지**"를 추천합니다.
  그래서 peek 라벨도 `아이디어 발전 도구 추천` 으로 다르게 표시됩니다.

각 도구마다 고유한 아이콘과 색이 정해져 있어,
펼치지 않은 상태에서도 색과 아이콘만으로 도구의 종류를 구분할 수 있습니다.

---

## 5. 아이디어 레이어의 ⓘ 버튼

아이디어 레이어의 오른쪽 위에는 작은 **ⓘ(정보) 버튼**이 있습니다.
이 버튼은 레이어를 넘기는 것과는 별개로, 클릭하면 **사이드 패널**이 열려
해당 아이디어에 대한 더 자세한 정보(생성 과정, 질문/답변, UX 평가 등)를 보여줍니다.

> 정리하면 카드에는 두 가지 진입점이 있습니다.
> - **하단 peek 클릭** → 카드 안에서 도구 레이어로 넘김 (레이어 전환)
> - **ⓘ 버튼 클릭** → 카드 바깥에 사이드 패널로 상세 정보 표시

---

## 6. 한눈에 보는 요약

- 아이디어 카드 = **아이디어 레이어(앞) + 도구 레이어(뒤)** 두 겹 구조
- 도구 레이어는 평소 **하단 띠(peek)만 노출** → 도구의 존재를 항상 암시
- peek을 **클릭하면 큐카드 넘기듯 두 레이어가 앞뒤로 교체**되며 도구 내용이 드러남
- `아이디어 확인하기` 를 누르면 **역방향으로 다시 아이디어 면으로 복귀**
- 도구 레이어 내용은 카드 종류(확장/변형/직접작성)에 따라
  **"사용된 도구 설명" 또는 "추천 도구"** 로 달라짐
