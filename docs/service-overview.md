# IdeaLine 서비스 소개

## 서비스 한 줄 소개

> **IdeaLine**은 체계적인 사고 도구와 AI를 결합하여 하나의 아이디어를 다양한 방향으로 발산하고 발전시킬 수 있는 아이디어 발산 플랫폼입니다.

---

## 어떤 서비스인가요?

아이디어를 떠올리는 것은 어렵습니다. 특히 **"더 발전시키기"** 는 더 어렵습니다.

IdeaLine은 사용자가 탐색하고 싶은 키워드나 공모전 주제를 입력하면, AI가 초기 아이디어를 생성하고, 이를 BCC·ERRC 사고 프레임워크를 통해 다양한 방향으로 확장하고 변형할 수 있도록 돕습니다. 모든 아이디어는 트리 구조의 시각적 캔버스 위에 펼쳐져, 생각의 흐름과 발전 과정을 한눈에 파악할 수 있습니다.

---

## 누구를 위한 서비스인가요?

- 공모전에 참여하며 다양한 아이디어를 발산해야 하는 **학생**
- 초기 서비스 아이디어를 검증하고 싶은 **스타트업 창업자**
- 기존 제품의 개선 방향을 체계적으로 찾고 싶은 **기획자 / PM**
- 브레인스토밍을 구조화하고 싶은 **혁신팀 / R&D 부서**

---

## 핵심 화면

### 1. 홈 — 아이디어 입력
키워드나 주제를 입력하면 AI가 초기 아이디어(씨드카드)를 생성하고, 자동으로 캔버스가 열립니다. 하단 작업공간에서 이전에 만든 캔버스 목록도 확인할 수 있습니다.

### 2. 캔버스 — 아이디어 맵
캔버스는 아이디어가 뻗어나가는 공간입니다. 씨드카드(초기 아이디어)를 중심으로 파생카드들이 트리 구조로 펼쳐집니다. 카드를 선택하면 아이디어를 더 발전시킬 수 있는 도구들이 활성화됩니다.

---

## 아이디어를 발전시키는 3가지 방법

### 확장하기 (BCC 프레임워크)
기존 아이디어에서 새로운 방향을 탐색합니다.

| 방향성 | 예시 도구 |
|---|---|
| 없애거나 바꾸기 | 제거, 대체, 분할·분리 |
| 합치거나 더하기 | 용도통합, 결합, 복제 |
| 뒤집거나 재정의 | 역전, 재정의 |
| 외부 힌트 활용 | 유추, 연결, 속성 의존성 |

방향성 선택 → 도구 선택 → AI 질문에 답변 → 새로운 아이디어 카드 자동 생성의 단계로 진행됩니다.

### 변형하기 (ERRC 프레임워크)
기존 아이디어의 요소를 전략적으로 조정합니다.

| 방향성 | 의미 |
|---|---|
| 강화(Raise) | 지금보다 더 키울 요소 |
| 감소(Reduce) | 줄이거나 약화할 요소 |
| 신설(Create) | 새로 추가할 요소 |
| 제거(Eliminate) | 과감하게 없앨 요소 |

방향성 선택 → AI 질문에 답변 → 변형된 아이디어 카드 생성의 단계로 진행됩니다.

### 직접 작성
프레임워크 없이 자유롭게 아이디어를 적어 카드로 추가할 수 있습니다.

---

## 아이디어 카드의 구조

각 카드는 **두 개의 레이어**로 구성되어 있습니다.

- **아이디어 레이어 (앞면)** — 아이디어의 제목과 설명
- **도구 레이어 (뒷면)** — 이 아이디어를 만드는 데 사용된 사고 도구와 질문·답변

카드 하단을 클릭하면 두 레이어를 자유롭게 전환할 수 있으며, 카드의 ⓘ 아이콘을 누르면 생성 과정 상세 정보와 AI 평가 결과를 사이드 패널에서 확인할 수 있습니다.

---

## AI 자동 UX 평가

씨드카드가 생성될 때, AI는 아이디어를 **3가지 영역 7개 항목**으로 자동 평가합니다.

- **Business** — 비즈니스 가치·실현 가능성
- **Human** — 사용자 경험·공감도
- **Social** — 사회적 가치·영향

별도 작업 없이 아이디어의 품질을 즉시 파악할 수 있습니다.

---

## 서비스 차별점 요약

| 항목 | IdeaLine의 접근 |
|---|---|
| 발산 방식 | AI 즉흥 추천이 아닌 BCC·ERRC 검증 프레임워크 기반 |
| 시각화 | 아이디어 간 관계를 트리 구조 맵으로 표현 |
| 카드 인터랙션 | 아이디어 면·도구 면을 한 카드 안에서 오가는 이중 레이어 구조 |
| 자동 평가 | 아이디어 생성과 동시에 UX 7개 항목 평가 제공 |
| 발산 단계 구조화 | 방향성 → 도구 → 질문·답변 → 생성의 명확한 프로세스 |

---

## 사용자 흐름 요약

```
키워드 입력
    ↓
AI가 초기 아이디어(씨드카드) + UX 평가 생성
    ↓
캔버스에서 카드 선택
    ↓
확장하기 / 변형하기 / 직접 작성으로 새 카드 생성
    ↓
아이디어 트리가 점점 넓어짐
    ↓
카드 상세 보기로 생성 과정 · 평가 확인
```
