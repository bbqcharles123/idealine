# 아이디어 카드 예시 데이터 가이드

IdeaLine 아이디어 카드의 예시 데이터를 생성하기 위한 가이드입니다.

---

## 1. 카드 구조

아이디어 카드는 **두 개의 레이어**로 구성됩니다.

```
┌─────────────────────────────────────┐
│  아이디어 레이어                      │  ← 제목 + 본문
│                                     │
├─────────────────────────────────────┤
│  도구 레이어 (하단에 살짝 노출)        │  ← 도구 안내 텍스트
└─────────────────────────────────────┘
```

---

## 2. 카드 종류별 표시 내용

### 씨드카드

| 영역 | 표시 내용 |
|------|-----------|
| 아이디어 레이어 | 제목 / 본문 |
| 도구 레이어 | 없음 |

**필요한 데이터**
```
title        — 아이디어 제목 (한 줄)
description  — 아이디어 본문 (2~3문장)
```

---

### 확장하기 / 변형하기 파생카드

| 영역 | 표시 내용 |
|------|-----------|
| 아이디어 레이어 | 제목 / 본문 |
| 도구 레이어 (접힘) | 왼쪽: "아이디어 생성 도구" / 오른쪽 칩: 도구명 |
| 도구 레이어 (펼침) | 도구명 + 도구 설명 텍스트 |

도구 설명 텍스트는 도구명으로 자동 결정됩니다 (아래 3항 참고).

**필요한 데이터**
```
title        — 아이디어 제목 (한 줄)
description  — 아이디어 본문 (2~3문장, 부모 아이디어에서 도구를 적용해 발전된 내용)
tagType      — 'expand' (확장하기) 또는 'transform' (변형하기)
tagName      — 사용한 도구명 (아래 3항의 도구 목록에서 선택)
```

---

### 직접작성 파생카드

| 영역 | 표시 내용 |
|------|-----------|
| 아이디어 레이어 | 제목 / 본문 |
| 도구 레이어 (접힘) | 왼쪽: "아이디어 발전 도구 추천" / 오른쪽 칩: 추천 카테고리명 |
| 도구 레이어 (펼침) | 추천 카테고리명 + 기대효과 안내 텍스트 |

**필요한 데이터**
```
title        — 아이디어 제목 (한 줄)
description  — 아이디어 본문 (2~3문장)
writeRec     — 추천 도구 카테고리: 'expand' (확장하기) 또는 'transform' (변형하기)
writeExpect  — 추천 도구로 발전시켰을 때 기대효과 (1~2문장, 이 아이디어의 특성에 근거)
```

---

## 3. 도구 목록과 도구 레이어 설명 텍스트

도구 레이어(펼쳤을 때)에 표시되는 설명은 tagName에 따라 아래 텍스트가 자동으로 사용됩니다.
예시 데이터 생성 시 tagName만 정하면 되고, 설명 텍스트는 별도로 만들 필요 없습니다.

### 확장하기 (tagType: 'expand')

| tagName | 도구 레이어 설명 텍스트 (자동 적용) |
|---------|-------------------------------|
| 제거 | 당연히 있어야 한다고 생각하는 기능을 없애보세요. 없애도 되거나 오히려 더 단순하고 새로운 가치가 생길 수 있습니다. |
| 대체 | 현재 사용 중인 요소를 전혀 다른 것으로 바꿔보세요. 의외의 대체재가 오히려 더 좋은 경험을 만들어낼 수 있습니다. |
| 분할·분리 | 하나로 묶여있는 것을 나눠보세요. 분리해서 각각 따로 조작할 수 있게 되면 더 세밀한 경험이 가능해집니다. |
| 용도통합 | 전혀 달라 보이는 두 기능을 하나로 합쳐보세요. 합쳐졌을 때 각각보다 훨씬 편리한 새로운 경험이 만들어집니다. |
| 결합 | 서로 관련 없어 보이는 두 요소를 함께 묶어보세요. 각각 따로일 때보다 훨씬 강력한 새로운 가치가 생겨납니다. |
| 복제 | 이미 있는 요소를 하나 더 추가하되 조금 다르게 변형해보세요. 같은 듯 다른 요소가 새로운 가능성을 열어줍니다. |
| 역전 | 원래의 방향, 역할을 반대로 뒤집어보세요. 당연하다고 생각하는 것을 거꾸로 했을 때 새로운 활용이 생깁니다. |
| 재정의 | 이 서비스가 누구를 위한 것인지, 무엇을 해결하는지를 완전히 새롭게 정의해보세요. 방향 자체가 달라질 수 있습니다. |
| 유추 | 전혀 다른 분야의 방식이나 원리에서 힌트를 가져와보세요. 다른 세계의 해법이 이 아이디어의 돌파구가 됩니다. |
| 연결 | 전혀 상관없어 보이는 두 가지를 연결해보세요. 예상치 못한 연결이 기존에 없던 완전히 새로운 아이디어를 만듭니다. |
| 속성 의존성 | 외부 환경이나 상황에 따라 제품의 특성이 자동으로 바뀌도록 만들어보세요. 조건에 반응하는 제품이 됩니다. |

### 변형하기 (tagType: 'transform')

| tagName | 도구 레이어 설명 텍스트 (자동 적용) |
|---------|-------------------------------|
| 증가 | 지금보다 더 강화해야 할 요소가 무엇인지 찾아보세요. 기대 이상으로 높였을 때 경쟁 서비스와 확실히 달라집니다. |
| 감소 | 지나치게 많거나 복잡한 부분을 줄여보세요. 단순해질 때 오히려 사용자가 더 편하게 느끼는 경우가 많습니다. |
| 창출 | 지금까지 어떤 서비스도 제공하지 않았던 완전히 새로운 요소를 만들어보세요. 없는 것을 만드는 것이 차별화입니다. |
| 제거 | 업계에서 당연하게 제공하던 요소를 과감히 없애보세요. 없앴을 때 오히려 더 명확하고 강한 서비스가 될 수 있습니다. |

## 4. 기존 예시 데이터

씨드카드 1개 + 파생카드 3개 예시입니다.

---

### 씨드카드

```
title: AI 생활 루틴 코치 앱
description: AI가 사용자의 하루 일정, 수면, 식이 패턴 데이터를 분석해 개인 맞춤형 생활 루틴을 제안하는 서비스입니다.
             사용자의 피로도와 집중 시간대를 고려해 업무, 휴식, 운동 시간을 자동으로 추천하고 루틴을 지속적으로 최적화합니다.
```

---

### 파생카드 1 — 확장하기 / 복제

```
title: 상황별 루틴 분기 추천
description: 재택근무일과 출근일처럼 패턴이 달라지는 상황에 따라 루틴 추천을 별도로 구성하는 기능입니다.
             AI가 오늘 일정 유형을 감지해 그에 맞는 루틴 세트를 자동으로 선택해 제공하므로
             사용자가 매번 수동으로 조정하지 않아도 상황에 맞는 루틴을 바로 활용할 수 있습니다.
tagType: expand
tagName: 복제
```

카드에 표시되는 도구 레이어: "아이디어 생성 도구 | 복제" → 펼치면 위 3항의 복제 설명 텍스트 자동 표시

---

### 파생카드 2 — 확장하기 / 재정의

```
title: 온디맨드 루틴 피드
description: 알림이 루틴을 이끄는 방식 대신, 사용자가 앱을 열 때마다 현재 시각과 컨디션 데이터를 즉시 분석해
             지금 이 순간에 맞는 루틴을 제안하는 방식입니다.
             푸시 알림을 없애 알림 피로를 제거하고, 사용자가 원할 때 능동적으로 루틴을 확인하는 경험으로 전환합니다.
tagType: expand
tagName: 재정의
```

카드에 표시되는 도구 레이어: "아이디어 생성 도구 | 재정의" → 펼치면 위 3항의 재정의 설명 텍스트 자동 표시

---

### 파생카드 3 — 직접작성

```
title: 루틴 공유 커뮤니티
description: 나만의 루틴을 다른 사용자들과 공유하고, 비슷한 생활 패턴을 가진 사람들의 루틴을 참고할 수 있는 기능입니다.
             직장인, 학생, 육아맘 등 라이프스타일 태그를 기반으로 검색하고 마음에 드는 루틴을 내 앱에 바로 적용할 수 있습니다.
writeRec: expand
writeExpect: 확장하기 도구를 활용하면 커뮤니티의 루틴 공유 방식에 결합·통합을 적용해
             개인 루틴과 소셜 데이터를 연결하는 더 풍부한 경험을 만들 수 있습니다.
```

카드에 표시되는 도구 레이어: "아이디어 발전 도구 추천 | 확장하기" → 펼치면 writeExpect 텍스트 표시

---

## 5. 새 예시 데이터 생성 요청 형식

```
주제: [공모전 주제 또는 키워드]

요청:
- 씨드카드 1개: title, description
- 확장하기 파생카드: title, description, tagName (도구 지정 또는 자유 선택)
- 변형하기 파생카드: title, description, tagName
- 직접작성 파생카드: title, description, writeRec, writeExpect
```

**작성 규칙**
- title: 한 줄 제목
- description: 2~3문장. 씨드카드는 "누구를 위해 / 어떤 문제 / 어떻게 해결"을 담고, 파생카드는 부모 아이디어에서 해당 도구를 적용한 발전 내용을 담음
- tagName: 3항 도구 목록에 있는 정확한 이름 사용
- writeExpect: 추천 카테고리(확장하기/변형하기)로 이 아이디어를 발전시켰을 때 구체적으로 기대되는 효과 1~2문장
